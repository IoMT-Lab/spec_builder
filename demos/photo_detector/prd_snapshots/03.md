# PRD for Photo Detector I²C Driver – Unit Tests

Executive Summary

- Project Overview
  - Objective: Establish a comprehensive verification strategy for the PD_* I²C driver (AS7341 sensor interface) implemented on an STM32WB0x-based platform. The driver supports register reads/writes and LED on/off control, with a testing approach comprising host-based unit tests (Unity/CMock with a mocked I²C layer) and on-target integration tests (UART-based hardware harness exercising the full PD_* driver sequence on the embedded board with real sensor timing). Tests are integrated into CI (GitHub Actions) to flash firmware via OpenOCD/pyOCD, capture UART logs, and produce JUnit XML results.
  - Target Hardware and Driver: STM32WB0x (STM32WB05/STM32WB09) board running the PD_* driver for the AS7341 photo detector sensor.
  - Testing Approach:
    - Unit Tests: host-based, deterministic, using Unity/CMock with a mocked I²C backend to validate core driver logic (register semantics, LED state management, data path ingress/egress).
    - On-Target Tests: end-to-end integration on the STM32WB0x board using UART harness to exercise readiness waits, ID checks, threshold configuration, interrupt polling, and measurement validity with real sensor timing.
  - Success Criteria: ≥90% unit-test coverage for the driver module; reliable on-target integration sequences; deterministic CI results; well-documented test vectors and harness usage.
  - Deliverables: Reusable test harness, versioned test data sets, CI workflow (GitHub Actions) with OpenOCD/pyOCD flashing, UART log capture, and JUnit XML reporting.
